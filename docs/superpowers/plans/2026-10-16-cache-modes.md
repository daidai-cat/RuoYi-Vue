# Cache Modes Implementation Plan

**Goal:** 保留 Redis 代码，提供默认无需 Redis 的本地缓存模式。

**Architecture:** `RedisCache` 保持业务入口，本地实现使用同一注入类型；按 `ruoyi.cache.type` 互斥注册。保留 Redis 序列化、Lua 和监控路径，补齐本地分支。

**Tech Stack:** Java 17、Spring Boot 4、JUnit 5、ConcurrentHashMap。

## 实施步骤

- [x] 为本地缓存行为、模式选择、字典兼容、限流与监控编写测试，先验证失败。
- [x] 新增 `LocalCache`，保留原 Redis 实现，配置互斥 Bean。
- [x] 兼容字典读取与本地限流，不改业务调用。
- [x] 适配缓存监控接口和页面，保留 Redis 统计代码。
- [x] 补充切换说明，运行 Maven 测试与编译，独立审查改动。

## 验收

- 默认或显式 `local` 时，无 Redis 连接即可完成缓存初始化及核心业务缓存操作。
- 显式 `redis` 时，注册原 Redis 缓存与 Lua，保持原行为。
- 非法模式配置启动失败，禁止静默切换。
- TTL、覆盖写入、键查询、字典、本地原子限流和管理接口测试通过。
- 完整应用启动若受现有数据库配置限制，明确记录，不读取凭据。

## 验证结果

- Maven 七个模块编译和 24 项测试通过。
- Redis 自动配置开启、无 Redis 服务时，参数与字典的启动初始化测试通过。
- 本地缓存对可变对象执行与 Redis 相同的序列化规则，两个对象隔离回归测试通过；`DictUtils` 保持原代码。
- Vue 模板编译、本地零 Key 显示和两种模式图表分支验证通过。
- 独立审查发现的会话对象引用污染问题已修复，复审无遗留问题。
- 未连接真实数据库或 Redis 做整机启动和登录联调；未读取应用连接凭据。
