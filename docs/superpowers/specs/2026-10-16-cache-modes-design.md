# 本地缓存与 Redis 双模式

默认 `ruoyi.cache.type=local`，显式指定 `redis` 后恢复原 Redis 实现；切换后重启生效，不迁移缓存数据，不自动故障降级。

- 保留 `RedisCache` 和 `RedisConfig`，仅在 Redis 模式注册；本地实现继承现有缓存入口，业务注入无需批量修改。
- 本地缓存使用线程安全 Map，支持当前业务涉及的对象、过期、键查询和删除；定期清理过期项。
- 登录会话、验证码、错误次数、防重复提交和字典沿用原调用；本地对象读写使用与 Redis 相同的序列化规则隔离可变对象。
- 限流保持原 Redis Lua 实现，本地模式使用原子计数和固定过期窗口。
- 缓存管理支持两种模式；本地监控仅展示实际可用信息。
- 测试使用独立 Spring 上下文和生成的数据，不加载应用配置、不连接数据库或真实 Redis。

本地模式仅适合单实例；重启或切换模式会丢失会话、验证码、限流计数等内存数据。
