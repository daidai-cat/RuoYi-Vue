选择三天两夜行程方向

预算按人均约 1500 元，厦门动车往返，潮州与汕头各住一晚。

D1 潮州古城 → D2 潮州美食＋汕头 → D3 汕头慢游

均衡经典

牌坊街、广济桥、小公园、牛肉火锅与夜粥均覆盖。

A · 均衡经典（推荐）

景点、美食和休息时间最均衡，首次到潮汕更稳妥。

早茶 → 粿品 → 生腌 → 牛肉火锅 → 夜粥

美食优先

减少景点停留，按餐次组织路线，穿插老街散步消食。

B · 美食优先

体验密度高，但需要控制食量并接受较多短途打车。

晚出发 · 午休 · 少换点 · 咖啡茶馆

休闲慢游

每天安排一个核心片区，避开午后高温与赶场。

C · 休闲慢游

舒适度最高，但会舍弃部分经典景点和小吃。
